🔑 Setup Facebook

  1. Buka developers.facebook.com → Create App → Business
  2. Settings → Basic → Copy App ID & App Secret
  3. App Review → Request: pages_manage_posts, pages_manage_videos, pages_show_list
  4. Klik "OAuth Generate" di Pages tab → Login → Pilih Page
  5. Settings → Advanced → Connected Pages → tambahkan Page lo
  6. Page harus Professional (Business/Creator), bukan personal
